# Cyber Threat Intelligence Project: webcamXP Exposure Analysis and MISP Integration

About the Project

This project is dedicated to Cyber Threat Intelligence (CTI) and Open-Source Intelligence (OSINT) analysis of exposed webcamXP surveillance servers available on the public Internet.

The main objective of the project was to demonstrate a complete threat intelligence lifecycle:

Data Collection → Analysis → Normalization → Intelligence Sharing

The project combines passive reconnaissance using Shodan with threat analysis and integration into the Malware Information Sharing Platform (MISP).

⸻

Project Goals

* Identify publicly exposed webcamXP servers using passive OSINT techniques.
* Analyze potential cybersecurity and privacy risks.
* Collect and structure Indicators of Compromise (IOCs).
* Create a threat intelligence dataset.
* Deploy and configure a local MISP platform.
* Import, normalize, deduplicate, and publish threat data.

⸻

Project Tasks

Week 1

* Study Cyber Threat Intelligence concepts.
* Explore IOC, TTP, Attack Surface, and OSINT methodologies.
* Research MISP capabilities and intelligence-sharing workflows.

Week 2

* Perform passive reconnaissance using Shodan.
* Create custom Shodan queries (dorks).
* Identify exposed webcamXP servers.
* Analyze visual and technical data leakage.
* Build a Data Source Mapping Matrix.
* Classify threats and profile potential threat actors.

Week 3

* Deploy MISP using Docker.
* Configure all required services.
* Create MISP Events.
* Import Indicators of Compromise (IOCs).
* Perform data normalization and deduplication.
* Publish threat intelligence artifacts.

Artificial Intelligence Usage

Artificial Intelligence tools were used as supporting instruments during the project:

* Week 1: AI assisted in preparing and structuring the report, explaining CTI concepts, and improving academic writing.
* Week 2: AI helped organize OSINT findings, threat classifications, glossary definitions, and report formatting.
* Week 3: AI provided guidance for MISP installation, Docker deployment, troubleshooting, and report preparation.

AI was used as an assistant for documentation, technical explanations, and report generation, while all practical tasks, analysis, configuration, and validation were performed by the project authors.

⸻

Project Outcome

As a result, the project demonstrated a complete Cyber Threat Intelligence workflow:

1. Passive OSINT data collection.
2. Threat identification and risk analysis.
3. IOC extraction.
4. Data normalization and filtering.
5. Intelligence sharing through MISP.

The final output is a reusable CTI dataset and a fully functional MISP instance capable of storing, managing, and sharing cyber threat intelligence.
